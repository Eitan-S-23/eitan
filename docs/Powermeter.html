Project Overview

WirelessPowermeter 无线功率计

基于 Nations Technology N32WB031 微控制器的便携式无线功率测量设备。 集成高精度 INA226 功率监测芯片、160×128 RGB565 TFT LCD、BLE 5.0 无线广播， 支持三档自动量程切换（0–0.8 mA / 0–90 mA / 0–5 A）， 实时波形显示与参数配置，EEPROM 掉电保存校准参数。

任务调度

系统采用基于 TIM3 定时器（20 ms 周期）的协作式任务调度，共注册 4 个周期性任务：

任务 ID函数周期功能描述
0app_gui_task10 msGUI 更新，刷新波形图和数据标签
1Ina226GetPower20 000 msINA226 数据采集 + 自动量程切换检查
2bsp_key_scan_start30 ms按键扫描，消抖处理
3reset_key100 ms按键状态复位

TIM3 配置

// 定时器配置（n32wb03x_it.c）
// PCLK1 = 64 MHz，Prescaler=640-1，Period=10-1
// 定时器频率 = 64 MHz / 640 / 10 = 10 kHz → 中断周期 0.1 ms
// 任务调度基准 = 0.1 ms × N（N为配置计数）

TIM_Prescaler = 640 - 1;   // 分频: 64MHz / 640 = 100 kHz
TIM_Period    = 10 - 1;     // 周期: 100 kHz / 10 = 10 kHz (0.1 ms 中断)

// 中断优先级配置
NVIC_Priority = 1;          // 较高优先级，确保定时精度
任务调度函数 sc_create_task(id, func, period_ms) 将任务注册到调度表， TIM3 中断每 0.1 ms 触发一次，调度器累计计数后按周期调用各任务。

INA226 功率监测

INA226 是 TI 出品的高精度电流/电压/功率监测芯片，通过 I2C 接口与主控通信（7位地址 0x40，写地址 0x80）。 设备配置为连续模式，对总线电压和分流电压同时进行转换。

寄存器配置

寄存器地址配置值说明
Configuration0x000x8000自动模式，持续测量总线电压 + 分流电压
Calibration0x05动态计算CAL = 0.00512 / (CURRENT_LSB × R_SHUNT)
Bus Voltage0x02只读精度 1.25 mV/LSB，额定范围 0–36 V（寄存器满量程 40.96 V）
Shunt Voltage0x01只读精度 2.5 μV/LSB
Power0x03只读精度 25 × CURRENT_LSB (mW)
Current0x04只读精度 = CURRENT_LSB

校准值计算

// bsp_ina226.c - 校准寄存器写入
// 公式: CAL = 0.00512 / (CURRENT_LSB × R_SHUNT)

// 量程 RANGE_5A:   CAL = 0.00512 / (0.001A × 0.04Ω)   = 128
// 量程 RANGE_250MA: CAL = 0.00512 / (0.00001A × 0.78Ω) ≈ 657
// 量程 RANGE_2MA:  CAL = 0.00512 / (0.0000001A × 100Ω) = 512

void update_ina226_calibration(void) {
    uint16_t cal = (uint16_t)(0.00512 / (CURRENT_LSB * R_SHUNT));
    INA226_SendData(INA226_ADDR, INA226_REG_CALIBRATION, cal);
}

数据读取流程

1
GetVoltage() — 多次采样总线电压寄存器 (0x02)，取平均值，单位 mV
2
Get_Shunt_Current() — 读取电流寄存器 (0x04)，乘以 CURRENT_LSB 换算，支持负电流（有符号16位）
3
get_power() — 读取功率寄存器 (0x03)，乘以功率 LSB（25 × CURRENT_LSB）
4
auto_range_switch(I_current) — 将当前电流值传入量程切换模块，判断是否需要档位调整

量程与校准

三个量程通过独立 GPIO 控制 MOS 管来切换不同采样电阻，每个量程有独立的 CURRENT_LSB 和 R_SHUNT 配置：

量程枚举采样电阻控制 GPIO向上切换阈值向下切换阈值
RANGE_2MA (0)100 Ω (PB1)PB10.8 mA—
RANGE_250MA (1)780 mΩ (PB2)PB290 mA0.8 mA
RANGE_5A (2)40 mΩ (PB3)PB3—40 mA

量程切换函数

// range_switch.c
void set_current_range(CurrentRange range) {
    // 关闭所有量程 GPIO
    GPIO_WriteBit(GPIOB, GPIO_PIN_1 | GPIO_PIN_2 | GPIO_PIN_3, Bit_RESET);

    switch(range) {
        case RANGE_2MA:
            GPIO_WriteBit(GPIOB, GPIO_PIN_1, Bit_SET);  // 100Ω
            R_SHUNT      = 100.0f;
            CURRENT_LSB  = 0.0000001;  // 0.1 μA
            break;
        case RANGE_250MA:
            GPIO_WriteBit(GPIOB, GPIO_PIN_2, Bit_SET);  // 780mΩ
            R_SHUNT      = 0.78f;
            CURRENT_LSB  = 0.00001;    // 10 μA
            break;
        case RANGE_5A:
            GPIO_WriteBit(GPIOB, GPIO_PIN_3, Bit_SET);  // 40mΩ
            R_SHUNT      = 0.04f;
            CURRENT_LSB  = 0.001;      // 1 mA
            break;
    }
    update_ina226_calibration();  // 重新写入校准寄存器
}

自动量程切换算法

自动量程切换采用带防抖（迟滞）的状态机，避免在阈值附近频繁切换量程：

// range_switch.c - 自动量程切换核心逻辑
#define HYSTERESIS_THRESHOLD  1   // 防抖触发次数

CurrentRange auto_range_switch(float current_ma) {
    float abs_current = fabs(current_ma);
    CurrentRange cur = get_current_range();

    if (cur == RANGE_2MA) {
        if (abs_current > 0.8f) {            // 超出 0.8mA → 切换到 RANGE_250MA
            hysteresis_counter++;
            if (hysteresis_counter >= HYSTERESIS_THRESHOLD) {
                set_current_range(RANGE_250MA);
                hysteresis_counter = 0;
            }
        } else { hysteresis_counter = 0; }

    } else if (cur == RANGE_250MA) {
        if (abs_current > 90.0f) {           // 超出 90mA → 切换到 RANGE_5A
            set_current_range(RANGE_5A);
        } else if (abs_current < 0.8f) {     // 低于 0.8mA → 切换回 RANGE_2MA
            set_current_range(RANGE_2MA);
        }

    } else if (cur == RANGE_5A) {
        if (abs_current < 40.0f) {           // 低于 40mA → 切换回 RANGE_250MA
            set_current_range(RANGE_250MA);
        }
    }
    return get_current_range();
}
向上切换（精度降低）采用防抖计数，需要连续 HYSTERESIS_THRESHOLD 次超阈值才执行； 向下切换（精度提高）直接执行，确保快速响应小电流测量需求。

浮点参数编码算法

将浮点数编码为 EEPROM 可存储的整数对 (a, b)，满足 value ≈ a × 10b：

// 例：R_SHUNT = 0.04 → a=4, b=-2  (0.04 = 4 × 10^-2)
// 例：CURRENT_LSB = 0.001 → 存储 log10(0.001) = -3

void encode_r_shunt(float value, uint8_t *a, int8_t *b) {
    int exp = (int)floor(log10(fabs(value)));
    float mantissa = value / pow(10, exp);  // 1.0 ≤ mantissa < 10
    *a = (uint8_t)round(mantissa * 10);     // 乘以10存为整数 (10–99)
    *b = (int8_t)(exp - 1);
}

AT24C02 EEPROM 存储

AT24C02 通过 I2C1 接口连接，用于掉电保存量程校准参数，确保每次开机恢复上次使用的配置：

// i2c_eeprom.c - 基础读写接口
void I2C_EE_WriteByte(uint8_t addr, uint8_t data) {
    I2C_GenerateSTART(I2C1, ENABLE);
    // ... 等待 ACK，发送设备地址 0xA0
    I2C_SendData(I2C1, addr);   // 写入字节地址
    I2C_SendData(I2C1, data);   // 写入数据
    I2C_GenerateSTOP(I2C1, ENABLE);
    Delay_Ms(5);                // 等待内部写周期
}

uint8_t I2C_EE_ReadByte(uint8_t addr) {
    // 先写地址，再重新 START 切换为读模式
    I2C_GenerateSTART(I2C1, ENABLE);
    // ... 发送 0xA0 (写)，发送字节地址
    I2C_GenerateSTART(I2C1, ENABLE);
    // ... 发送 0xA1 (读)，读取数据
    return I2C_ReceiveData(I2C1);
}
AT24C02 写操作后需等待约 5 ms 完成内部 EEPROM 写周期，写入期间不可再次访问设备。 每字节写寿命约 100 万次，量程切换时按需写入，避免频繁写操作。

// app_gui.c - 按键命令处理
void app_gui_key_handler(uint8_t cmd) {
    if (current_page == PAGE_WAVEFORM) {
        if (cmd == CMD_RIGHT) switch_to_page(PAGE_CONFIG);

    } else if (current_page == PAGE_CONFIG) {
        switch(cmd) {
            case CMD_LEFT:   // 返回波形页，保存修改的参数
                save_range_config_to_eeprom();
                switch_to_page(PAGE_WAVEFORM);
                break;
            case CMD_RIGHT:  // 高亮选中下一个参数
                selected_param = (selected_param + 1) % PARAM_COUNT;
                break;
            case CMD_UP:     // 增大当前参数值 × 10
                adjust_param(selected_param, +1);
                break;
            case CMD_DOWN:   // 减小当前参数值 ÷ 10
                adjust_param(selected_param, -1);
                break;
        }
    }
}

// app_gui.c - 页面2 参数调整逻辑
// 按右键高亮选中参数，上/下键调整值（×10 或 ÷10）
// 按左键时自动调用 save_range_config_to_eeprom() 保存

void adjust_param(uint8_t param_idx, int direction) {
    switch(param_idx) {
        case PARAM_R_STEP:
            R_STEP = (direction > 0) ? R_STEP * 10 : R_STEP / 10;
            break;
        case PARAM_R_SHUNT:
            R_SHUNT = (direction > 0) ? R_SHUNT * 10 : R_SHUNT / 10;
            update_ina226_calibration();
            break;
        case PARAM_CURRENT_LSB:
            CURRENT_LSB = (direction > 0) ? CURRENT_LSB * 10 : CURRENT_LSB / 10;
            update_ina226_calibration();
            break;
    }
}

N32WB031 集成 BLE 5.0 射频，设备以 iBeacon 格式广播测量数据， 方便手机 APP 或 BLE 扫描仪实时读取电流和电压值。

// 广播数据更新（50 ms 周期）：将测量值编码到 Major/Minor
ibc_data[25] = (uint8_t)(I_current >> 8);
ibc_data[26] = (uint8_t)(I_current & 0xFF);
ibc_data[27] = (uint8_t)((uint16_t)I_voltage >> 8);
ibc_data[28] = (uint8_t)((uint16_t)I_voltage & 0xFF);
设备名称通过 CUSTOM_DEVICE_NAME 宏定义，可在广播扫描列表中识别。 广播数据每 50 ms 更新一次，确保手机端接收到最新测量值。

通信协议

I2C 通信时序（INA226 寄存器写）

1
等待总线空闲 — 检测 SCL/SDA 均为高电平
2
发送 START — SDA 高→低跳变（SCL 高电平期间）
3
发送设备地址 — 7位地址 0x40 + 写位(0) = 0x80，等待 ACK
4
发送寄存器地址 — 1字节寄存器指针，等待 ACK
5
发送数据高字节 — 16位数据高8位，等待 ACK
6
发送数据低字节 — 16位数据低8位，等待 ACK
7
发送 STOP — SDA 低→高跳变（SCL 高电平期间），释放总线
