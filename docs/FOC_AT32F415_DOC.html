Project Overview

FOC_AT32F415 驱动板程序

基于雅特力 AT32F415CBT7（Cortex-M4，150 MHz）的双电机 FOC 驱动板，包含 25 个独立 Keil MDK-ARM V5 工程， 从开环速度到完整 dq 轴电流闭环，覆盖 BLDC、步进电机、多种编码器及 SimpleFOC Studio 实时调试等完整应用场景。 所有工程共用 foc_lib/ 统一驱动库，通过独立的 at32f415_conf.h 管理外设使能。

AT32F415CBT7 · 150 MHz Cortex-M4 双路 BLDC FOC 步进电机 FOC AS5600 I²C AS5047P SPI ABI 正交 霍尔传感器 SimpleFOC Studio 蓝牙 UART 在线电流检测

PROJECT 01

双电机 BLDC 开环速度控制

BLDC × 2 无编码器 开环速度 极对数 7 12.6 V

最基础的 BLDC 演示工程，无需任何位置传感器。程序通过对电角度积分产生旋转磁场，以固定速度驱动 M0 和 M1 同步旋转（10 rad/s）。电机无法感知实际位置，故对负载变化无法补偿，适合验证 PWM 输出和三相驱动电路是否正常工作。

外设配置

外设引脚功能
TMR1 / TMR3PA8/PA9/PA10 + PB4/PB5/PB0M0/M1 三相 20 kHz PWM
USART2PA2 TX / PA3 RX调试打印

核心代码

bldc_init(&motor0, 0, 7, 12.6f);   /* motor_id=0, 极对数=7, 电源=12.6V */
bldc_init(&motor1, 1, 7, 12.6f);
motor0.controller = BLDC_CTRL_VEL_OPENLOOP;
motor1.controller = BLDC_CTRL_VEL_OPENLOOP;
bldc_init_hardware(&motor0);
bldc_init_hardware(&motor1);
bldc_init_foc(&motor0, 0.0f, get_micros());
bldc_init_foc(&motor1, 0.0f, get_micros());

while (1) {
    bldc_move(&motor0, 10.0f);   /* 目标速度 10 rad/s */
    bldc_move(&motor1, 10.0f);
}
开环模式下 bldc_move() 的参数直接作为速度目标，内部以固定步长积分电角度，无 PID 参与。这是调试驱动板最简单的方式。
PROJECT 02

双电机 BLDC 开环位置扫描

BLDC × 2 无编码器 开环位置 ±2π rad 扫描

在开环模式下以位置目标驱动电机，程序以 1 ms 为步长不断递增目标角度，实现从 −2π 到 +2π 的连续正反扫描。由于没有编码器，实际转子位置与指令之间可能有偏差（取决于负载），主要用于验证 FOC 相序、 SVM 生成及驱动电路三相平衡性。

外设配置

外设引脚功能
TMR1 / TMR3PA8/PA9/PA10 + PB4/PB5/PB0M0/M1 三相 PWM
USART2PA2 / PA3调试打印

核心代码

motor0.controller = BLDC_CTRL_ANGLE_OPENLOOP;
motor1.controller = BLDC_CTRL_ANGLE_OPENLOOP;
/* ... init ... */
float angle = 0.0f;
while (1) {
    angle += 0.001f;
    if (angle > 6.28318f) angle = -6.28318f;
    bldc_move(&motor0, angle);
    bldc_move(&motor1, angle);
    delay_ms(1);
}
开环位置模式以 angle 直接映射为旋转磁场方向，不经过速度 PID。步长 0.001 rad/ms 对应约 1 rad/s 的等效角速度。
PROJECT 03

IIC 双路 AS5600 磁编码器测试

AS5600 × 2 I²C1 + I²C2 角度读取 速度估算 200 ms 刷新

验证双路 AS5600 磁编码器的 I²C 通信是否正常。M0 使用 I2C1（PB8/PB9，需 I2C1_MUX remap），M1 使用 I2C2（PB10/PB11，默认映射）。AS5600 内部为 12-bit 绝对角度（0–4095 → 0–2π rad），foc_lib 在读取原始值后做角度归一化和一阶差分速度估算，通过串口每 200 ms 打印一次双路数据。

外设配置

外设引脚功能
I2C1（remap）PB8 SCL / PB9 SDAAS5600 M0
I2C2PB10 SCL / PB11 SDAAS5600 M1
USART2PA2 / PA3串口打印

核心代码

as5600_init_m0();   /* 初始化 I2C1 PB8/PB9，内部执行 I2C1_MUX remap */
as5600_init_m1();   /* 初始化 I2C2 PB10/PB11 */

while (1) {
    as5600_update_m0(&enc0, get_micros());  /* 读角度+估算速度 */
    as5600_update_m1(&enc1, get_micros());
    printf("M0: %.4f rad  %.2f rad/s | M1: %.4f rad  %.2f rad/s\r\n",
           enc0.angle, enc0.velocity, enc1.angle, enc1.velocity);
    delay_ms(200);
}
AS5600 地址固定为 0x36，两路通过不同 I²C 总线区分。若同一总线需挂多个 AS5600，需配置 ADDR 引脚改变地址。
PROJECT 04

ABI 正交编码器测试

ABI 正交编码器 TMR2 编码器模式 CPR 4096 计数 + 速度

使用 AT32F415 的 TMR2 硬件编码器模式（双沿计数，TMR_ENCODER_MODE_C），将 A/B 相正交信号映射到 PA0（CH1）和 PA1（CH2），硬件自动完成方向判断和计数增减。foc_lib 将 TMR2 计数值转换为弧度角度并用一阶差分估算速度，每 200 ms 打印一次。CPR 4096 意味着每转硬件计数 16384 脉冲（4× 模式）。

外设配置

外设引脚功能
TMR2 编码器模式PA0 CH1(A相) / PA1 CH2(B相)正交计数，自动方向
USART2PA2 / PA3串口打印

核心代码

enc.cpr = 4096;           /* 每转计数 4096（× 4 = 16384 脉冲）*/
encoder_abi_init(4096);   /* 配置 TMR2 编码器模式，计数上限 0xFFFF */

while (1) {
    encoder_abi_update(&enc, get_micros());
    printf("angle: %.4f rad  vel: %.2f rad/s  cnt: %ld\r\n",
           enc.angle, enc.velocity, (long)enc.count);
    delay_ms(200);
}
TMR2/TMR5 基础架构为 16-bit 计数器，但其 CVAL/PR 寄存器宽度为 32-bit，可扩展为 32-bit 模式（0–4294967295），DS 将其直接列为"2 x 32-bit timers"。用作编码器接口时，启用 32-bit 模式可彻底避免高速旋转的计数溢出问题（RM §14.1.2）。
PROJECT 05

双电机 BLDC 闭环速度控制

BLDC × 2 AS5600 × 2 闭环速度 目标 5 rad/s 速度 PID

以 AS5600 作为位置反馈，实现 PID 速度闭环控制。主循环在每次迭代中先更新两路编码器数据，再调用 bldc_loop_foc() 执行 Park 变换，最后由 bldc_move(5.0f) 触发速度 PID 计算目标 Uq 并输出。即使负载突然变化，PID 也能通过调节 Uq 维持目标速度，是最基础的实用闭环工程。

外设配置

外设引脚功能
I2C1（remap）PB8 / PB9AS5600 M0
I2C2PB10 / PB11AS5600 M1
TMR1 / TMR3PA8/PA9/PA10 + PB4/PB5/PB0双路三相 PWM
USART2PA2 / PA3调试打印

控制主循环

while (1) {
    uint32_t now = get_micros();
    as5600_update_m0(&enc0, now);
    as5600_update_m1(&enc1, now);
    bldc_loop_foc(&motor0, enc0.angle, now);  /* Park 变换，计算 Ud/Uq */
    bldc_loop_foc(&motor1, enc1.angle, now);
    bldc_move(&motor0, 5.0f);   /* 速度 PID：目标 5 rad/s */
    bldc_move(&motor1, 5.0f);
}
此工程是 AS5600 + BLDC 闭环的最小完整示例，建议先用本工程验证 PID 参数，再移植到 06/07 等高级控制工程。
PROJECT 06

双电机 BLDC 闭环位置控制

BLDC × 2 AS5600 × 2 闭环位置 目标 0 rad 双环 PID

在速度闭环的基础上增加外环角度 PID，实现双环（位置外环 + 速度内环）闭环控制。目标角度设为 0 rad（上电时的初始位置），电机会主动保持在目标角度，对外部扰动有抵抗能力。启动时先读取当前编码器角度作为 FOC 初始化参考，避免启动冲击。

控制主循环

motor0.controller = BLDC_CTRL_ANGLE;
motor1.controller = BLDC_CTRL_ANGLE;
/* ... 初始化编码器和硬件 ... */
while (1) {
    uint32_t now = get_micros();
    as5600_update_m0(&enc0, now);
    as5600_update_m1(&enc1, now);
    bldc_loop_foc(&motor0, enc0.angle, now);
    bldc_loop_foc(&motor1, enc1.angle, now);
    bldc_move(&motor0, 0.0f);   /* 位置目标 0 rad，保持不动 */
    bldc_move(&motor1, 0.0f);
}
位置模式下 bldc_move(target_rad) 中的参数为绝对角度目标（单位 rad）。若需要多圈跟踪，需根据实际应用对角度做累计处理。
PROJECT 07

双电机闭环位置–力矩互控

BLDC × 2 AS5600 × 2 M0 位置控制 M1 力矩控制

两路电机采用不同控制模式：M0 作为从动轴跟随位置目标（1.0 rad），M1 以固定力矩电压（Uq = 0.5 V）抵抗 M0 的运动，模拟机械臂与弹簧的联合作用场景。此工程展示了 foc_lib 多模式独立运行的能力，两套 PID 参数互不干扰。

电机控制模式目标说明
M0BLDC_CTRL_ANGLE1.0 rad闭环跟随角度目标
M1BLDC_CTRL_TORQUE_VOLTAGE0.5 V (Uq)持续施加固定力矩
motor0.controller = BLDC_CTRL_ANGLE;
motor1.controller = BLDC_CTRL_TORQUE_VOLTAGE;
/* ... */
while (1) {
    /* FOC 计算同时进行 */
    bldc_loop_foc(&motor0, enc0.angle, now);
    bldc_loop_foc(&motor1, enc1.angle, now);
    bldc_move(&motor0, 1.0f);   /* M0: 位置 1 rad */
    bldc_move(&motor1, 0.5f);   /* M1: Uq=0.5V 力矩 */
}
PROJECT 08

灯哥开源机器狗专用程序（串口控制关节）

BLDC × 2 AS5600 × 2 蓝牙 USART1 关节角度控制 F/B/S 命令

面向灯哥开源四足机器狗关节的专用驱动程序，两路 BLDC 均工作在角度闭环模式，通过 USART1（PB6/PB7，需 USART1_MUX remap）接收蓝牙串口命令实时更新关节目标角度。支持三条命令：'F'（前进，目标 ±1 rad）、'B'（后退，目标 ∓1 rad）、'S'（停止，目标 0 rad）。

外设配置

外设引脚功能
USART1（remap）PB6 TX / PB7 RX蓝牙模块，9600 bps
I2C1/I2C2PB8-PB9 / PB10-PB11AS5600 M0/M1
TMR1 / TMR3PA8/PA9/PA10 + PB4/PB5/PB0双路 PWM
USART2PA2 / PA3调试打印

命令解析

/* 主循环中轮询 USART1 接收缓冲 */
if (usart_flag_get(USART1, USART_RDBF_FLAG) != RESET) {
    uint8_t cmd = (uint8_t)usart_data_receive(USART1);
    if (cmd == 'F') { t0 =  1.0f; t1 =  1.0f; }  /* 前进 */
    if (cmd == 'B') { t0 = -1.0f; t1 = -1.0f; }  /* 后退 */
    if (cmd == 'S') { t0 =  0.0f; t1 =  0.0f; }  /* 停止 */
}
bldc_move(&motor0, t0);
bldc_move(&motor1, t1);
PB6/PB7 被 USART1 占用，此工程不能同时启用霍尔传感器 M1（引脚冲突）。两者必须二选一。
PROJECT 09

双电机完整 FOC 力矩控制（含在线电流检测）

BLDC × 2 AS5600 × 2 电流检测 × 4 力矩电压控制 Uq = 0.3 V

最完整的 BLDC 力矩控制工程，在闭环 FOC 基础上增加了 4 路在线电流采样（PA4/PA5 对应 M0 的 Ia/Ib，PA6/PA7 对应 M1 的 Ia/Ib）。上电后先对两路电流传感器进行零偏校准（current_sense_calibrate()），然后进入主循环同时更新编码器角度和电流值，以固定力矩电压 Uq = 0.3 V 驱动电机。可作为电流闭环控制的基础框架。

外设配置

外设引脚功能
ADC1 CH4/CH5PA4 / PA5M0 相电流 Ia / Ib
ADC1 CH6/CH7PA6 / PA7M1 相电流 Ia / Ib
I2C1/I2C2PB8-PB11AS5600 双路编码器
TMR1 / TMR3PA8-PA10 + PB4/PB5/PB0三相 PWM
current_sense_init();
current_sense_calibrate(0, &cs0);   /* M0 零偏校准 */
current_sense_calibrate(1, &cs1);   /* M1 零偏校准 */
/* ... FOC 初始化 ... */
while (1) {
    as5600_update_m0(&enc0, now);
    as5600_update_m1(&enc1, now);
    current_sense_read(0, &cs0);    /* 读取 M0 Ia/Ib */
    current_sense_read(1, &cs1);    /* 读取 M1 Ia/Ib */
    bldc_loop_foc(&motor0, enc0.angle, now);
    bldc_loop_foc(&motor1, enc1.angle, now);
    bldc_move(&motor0, 0.3f);       /* Uq = 0.3 V */
    bldc_move(&motor1, 0.3f);
}
当前电流值仅作监测，未接入电流闭环 PID。如需真正的 dq 轴电流控制，可将 cs0.Ia/Ib 传入 Clarke/Park 变换并闭合 Id/Iq 回路。
PROJECT 10

旋钮与电机速度协同控制

BLDC × 2 AS5600 × 2 M0 作旋钮 M1 跟随速度

有趣的人机交互工程：M0 设置为力矩电压 0（相当于可自由转动的旋钮），用户手动拨动 M0 轴；M1 的速度目标实时等于 M0 当前测量到的角速度，实现"用手旋转 M0 来控制 M1 转速"。体现了 SimpleFOC 框架中用一路电机的编码器输出驱动另一路电机的灵活性。

motor0.controller = BLDC_CTRL_TORQUE_VOLTAGE;  /* M0: 自由转动（旋钮）*/
motor1.controller = BLDC_CTRL_VELOCITY;        /* M1: 跟随速度 */
while (1) {
    as5600_update_m0(&enc0, now);
    as5600_update_m1(&enc1, now);
    bldc_loop_foc(&motor0, enc0.angle, now);
    bldc_loop_foc(&motor1, enc1.angle, now);
    bldc_move(&motor0, 0.0f);              /* Uq=0，自由旋转 */
    bldc_move(&motor1, motor0.shaft_vel);  /* M1 速度 = M0 速度 */
}
实际应用中建议对 motor0.shaft_vel 加一阶低通滤波后再传给 M1，以避免手抖引起速度指令抖动。
PROJECT 11

SimpleFOC Studio 实时调参（M0 端）

PROJECT 25

重力前馈补偿控制（机械臂保持水平）

BLDC M0 AS5600 M0 电流检测 位置 + 前馈 cos 重力补偿

最具工程意义的高级控制工程，在位置 PID 闭环的基础上叠加重力前馈项，使机械臂在任意位置都能抵消重力力矩，无需 PID 积分项承担重力负担，改善系统响应速度和稳态误差。前馈公式为 Ud = GRAVITY_FF × cos(shaft_angle)，其中 GRAVITY_FF（默认 0.5）需根据实际臂长和负载质量进行标定。

控制原理

1
位置 PID — 角度误差经双环 PID 计算出 Uq（切向力）
2
重力前馈 — 根据当前角度计算 Ud = k × cos(θ)，抵消径向重力分量
3
FOC 输出 — Ud/Uq 经 Park 逆变换 + SVM 生成三相 PWM
#define GRAVITY_FF  0.5f   /* 根据臂长×质量标定，单位 V */

while (1) {
    as5600_update_m0(&enc0, now);
    current_sense_read(0, &cs0);
    bldc_loop_foc(&motor0, enc0.angle, now);
    /* 注入前馈 Ud：叠加在 d 轴（产生径向力抵消重力） */
    motor0.Ud = GRAVITY_FF * cosf(motor0.shaft_angle);
    bldc_move(&motor0, 0.0f);   /* 位置目标：水平位置 0 rad */
}
标定方法：将机械臂水平放置（θ=0），逐渐增大 GRAVITY_FF 直到臂在 θ=90° 时能稳定保持，此时的值即为最优前馈增益。 典型值范围：轻型臂 0.2–0.8 V，重型臂 1.0–3.0 V（取决于供电电压和电机参数）。
