Project Overview

N32WB_HID 蓝牙触摸屏与键盘设备

N32WB_HID 是基于 Nations 半导体 N32WB03x 微控制器的 BLE HID（蓝牙低功耗人机接口设备）固件项目， 实现了完整的多点触控触摸屏模拟与 HID 键盘功能，并提供高层手势 API（缩放、旋转、截图、边缘滑动等）， 可作为无线触摸板或触控笔设备接入 Windows / Android / iOS 主机。

Nations N32WB03x BLE 5.x HOGPD 多点触控 3 指 HID 键盘 手势识别 API Keil MDK-ARM GATT HID Profile Windows 兼容
芯片: Nations N32WB03x  ·  设备名: hid_mouse  ·  IDE: Keil MDK-ARM  ·  固件版本: v1.0.0  ·  语言: C (ANSI C99)

系统启动流程

1
delay_n_10us(200*1000) — 上电延时 2 秒，预留 SWD 调试窗口，防止上电即进入睡眠
2
NS_LOG_INIT() — 初始化 USART 日志系统（ERROR / WARNING / INFO 三级别）
3
app_ble_init() — 初始化 BLE 协议栈，注册 HOGPD / BASS / DIS 三个 GATT 配置文件
4
app_key_configuration() — 配置按键 GPIO（用于测试触摸/键盘 HID 事件）
5
LedInit() / LedOn() — 初始化电源指示 LED（LED1）和连接状态 LED（LED2）并点亮电源灯
6
ResInit(GPIOB, GPIO_PIN_3) — 配置 PB3 为推挽输出，置高（detect_select），用于调试选择
7
while(1) { rwip_schedule(); ns_sleep(); } — 主循环：调度 BLE 所有挂起事件后进入低功耗睡眠
// main.c - 主函数精简版
int main(void) {
    delay_n_10us(200*1000);   // SWD 保持窗口
    NS_LOG_INIT();
    app_ble_init();           // BLE 协议栈 + GATT 配置文件初始化
    app_key_configuration();
    LedInit(LED1_PORT, LED1_PIN);
    LedOn(LED1_PORT, LED1_PIN);   // 电源 LED 常亮
    ResInit(GPIOB, GPIO_PIN_3);
    detect_select();
    while (1) {
        rwip_schedule();      // 调度 BLE 事件
        ns_sleep();           // 进入低功耗
    }
}

多点触控协议

本项目通过 BLE HOGPD 向主机发送符合 HID 规范的多点触控报告，支持最多 3 个同时触点，坐标系采用逻辑分辨率 32767×32767。

触点数据结构（5 字节/触点）

// app_hid_touchscreen.h
typedef struct __attribute__((packed)) {
    uint8_t  tip_switch : 1;   // 触摸状态：1=按下, 0=抬起
    uint8_t  contact_id : 7;   // 触点 ID (0-127)
    uint16_t x;                // X 坐标 (0-32767)
    uint16_t y;                // Y 坐标 (0-32767)
} hid_touch_point_t;           // 共 5 字节

// 多触点报告：3 个触点 × 5 字节 = 15 字节
typedef struct __attribute__((packed)) {
    hid_touch_point_t touches[MAX_TOUCH_POINTS];  // [0..2]
} hid_multitouch_report_t;

参数值说明
SCREEN_WIDTH32767X 轴最大逻辑坐标
SCREEN_HEIGHT32767Y 轴最大逻辑坐标
MAX_TOUCH_POINTS3最大同时触点数
报告 ID4（idx=3）HOGPD Report Index 3
报告长度15 字节3 × 5 字节，不含 contact_count

HID 报告字节布局

// 15 字节报告结构（Report ID 4）
// 每个触点占 5 字节，格式如下：
// offset+0: [tip_switch:1 | contact_id:7]  → Byte0
// offset+1: X 低字节 (LSB)
// offset+2: X 高字节 (MSB)
// offset+3: Y 低字节 (LSB)
// offset+4: Y 高字节 (MSB)
//
// 示例：触点 0 按下在屏幕中央 (16383, 16383)
// Byte0 = 0x01 | (0 << 1) = 0x01  (tip=1, id=0)
// Byte1 = 0xFF, Byte2 = 0x3F      (x = 0x3FFF = 16383)
// Byte3 = 0xFF, Byte4 = 0x3F      (y = 0x3FFF = 16383)
注意：报告中不含 contact_count 字节（已从描述符移除），Windows 多指触控在此配置下工作正常。

核心发送函数

// app_hid_touchscreen.c
void app_hid_send_multitouch(const hid_touch_point_t* touches, uint8_t count)
{
    uint8_t report[APP_HID_MULTITOUCH_REPORT_LEN];  // 15字节
    memset(report, 0, sizeof(report));

    for (uint8_t i = 0; i < MAX_TOUCH_POINTS; i++) {
        uint8_t offset = i * 5;
        if (i < count && touches != NULL) {
            // 活跃触点：写入 tip_switch + contact_id + X + Y
            const hid_touch_point_t* t = &touches[i];
            report[offset]   = (t->tip_switch ? 0x01 : 0x00) | ((t->contact_id & 0x7F) << 1);
            report[offset+1] = t->x & 0xFF;
            report[offset+2] = (t->x >> 8) & 0xFF;
            report[offset+3] = t->y & 0xFF;
            report[offset+4] = (t->y >> 8) & 0xFF;
        } else {
            report[offset] = (i << 1);   // 无触点：仅保留 contact_id
        }
    }
    // 通过 HOGPD 发送到主机
    ke_msg_send(req);
}

缩放手势实现示例

// app_gesture_zoom() - 双指捏合/展开
void app_gesture_zoom(uint8_t zoom_level, uint8_t is_zoom_in)
{
    uint16_t center_x = SCREEN_WIDTH / 2;   // 屏幕中心
    uint16_t center_y = SCREEN_HEIGHT / 2;

    // 基础距离 = 2000 + level*800 (像素)
    uint16_t base_distance = 2000 + (zoom_level * 800);
    uint16_t start_distance, end_distance;

    if (is_zoom_in) {
        start_distance = base_distance / 2;   // 放大：手指由近到远
        end_distance   = base_distance;
    } else {
        start_distance = base_distance;        // 缩小：手指由远到近
        end_distance   = base_distance / 2;
    }
    // 持续时间 300-800ms，调用底层 pinch 函数
    uint16_t duration_ms = 300 + (zoom_level * 50);
    app_touchscreen_pinch(center_x, center_y, start_distance, end_distance, duration_ms);
}

滑动插值逻辑

// app_touchscreen_swipe() - 10步线性插值滑动
void app_touchscreen_swipe(uint16_t x_start, uint16_t y_start,
                           uint16_t x_end,   uint16_t y_end,
                           uint16_t duration_ms)
{
    uint8_t  steps = 10;
    uint16_t delay_per_step = duration_ms / steps;
    int16_t  x_step = (x_end - x_start) / steps;
    int16_t  y_step = (y_end - y_start) / steps;

    // 按下
    app_hid_send_touchscreen(0, 1, x_start, y_start, 100);
    // 插值移动
    for (uint8_t i = 1; i < steps; i++) {
        current_x += x_step;
        current_y += y_step;
        app_hid_send_touchscreen(0, 1, current_x, current_y, 100);
        delay_n_ms(delay_per_step);
    }
    // 落点 + 抬起
    app_hid_send_touchscreen(0, 1, x_end, y_end, 100);
    delay_n_ms(10);
    app_hid_send_touchscreen(0, 0, x_end, y_end, 0);
}

BLE GATT 配置文件

设备实现了三个标准 Bluetooth SIG GATT Profile，通过 HOGPD 发送 HID 报告，通过 BASS/DIS 提供基础设备信息。

Profile缩写状态功能描述
HID Over GATT Profile Device HOGPD ✓ 启用 核心 HID 服务，负责发送触摸屏和键盘报告到主机
Battery Service BASS ✓ 启用 电池电量上报服务，主机可读取当前电量百分比
Device Information Service DIS ✓ 启用 设备信息服务，上报固件/硬件版本（均为 "1.0.0"）

BLE 事件处理流程

1
APP_BLE_OS_READY — BLE 协议栈就绪，开始广播（Fast Advertising：100ms 间隔）
2
APP_BLE_CONNECTED — 主机连接成功，熄灭广播 LED，设备进入已连接状态
3
APP_HID_READY — HOGPD 服务就绪（主机订阅通知），可开始发送 HID 报告
4
app_hid_send_multitouch() / send_keyboard() — 按需发送触摸屏或键盘报告
5
APP_BLE_DISCONNECTED — 连接断开，重新启动 Slow Advertising（2s 间隔，180s 超时）

HID 报告格式总览

设备向主机发送两类 HID 报告：触摸屏报告（Report ID 4）和键盘报告（Report ID 1）。

触摸屏报告（15 字节，Report ID 4）

字节偏移字段位宽说明
0[b0]tip_switch (Finger 0)1 bit手指是否接触屏幕
0[b7:1]contact_id (Finger 0)7 bit触点 ID = 0
1-2X coordinate (Finger 0)16 bitX 坐标，小端序
3-4Y coordinate (Finger 0)16 bitY 坐标，小端序
5-9Finger 1 (同上格式)40 bit触点 ID = 1
10-14Finger 2 (同上格式)40 bit触点 ID = 2

键盘报告（8 字节，Report ID 1）

字节偏移字段说明
0modifier修饰键位掩码（Ctrl/Shift/Alt/GUI）
1reserved保留字节，固定 0x00
2key[0]第 1 个按键键码
3key[1]第 2 个按键键码
4key[2]第 3 个按键键码
5key[3]第 4 个按键键码
6key[4]第 5 个按键键码
7key[5]第 6 个按键键码（最多 6 键同时）
两类报告均通过 HOGPD_REPORT_UPD_REQ 消息经 BLE GATT Notification 推送到主机， 主机无需轮询，低功耗且实时性高。

坐标与触点宏定义

// app_hid_touchscreen.h
#define SCREEN_WIDTH   32767   // X 轴逻辑最大值
#define SCREEN_HEIGHT  32767   // Y 轴逻辑最大值
#define MAX_TOUCH_POINTS  3    // 最大同时触点数

// 报告长度 = MAX_TOUCH_POINTS × 5字节
#define APP_HID_MULTITOUCH_REPORT_LEN  (MAX_TOUCH_POINTS * 5)  // = 15
开发注意：修改 MAX_TOUCH_POINTS 时，需同步更新 HID 报告描述符中的触点数量定义， 否则主机可能无法正确解析报告。描述符修改后需重新配对。
