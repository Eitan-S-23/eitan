FOC AT32F415 · 双路无刷电机驱动板

基于雅特力 AT32F415CBT7（Cortex-M4，150 MHz）的双路 FOC 驱动板固件库。 包含 25 个独立 Keil MDK-ARM 工程，循序渐进覆盖从开环速度控制 到 dq 轴电流闭环的完整学习路径，支持 BLDC 与步进电机，兼容四种编码器类型。

  • 25 个独立工程，由浅入深的 FOC 学习路径
  • 多编码器支持：AS5600（I²C）/ AS5047P（SPI）/ ABI 正交 / Hall 传感器
  • 封装完整 FOC 库（foc_lib/），可复用
  • dq 轴电流闭环控制 + 在线电流检测
  • SimpleFOC Studio 实时调参与波形监控
  • 蓝牙 UART 无线调试接口
  • 128 KB Flash / 32 KB RAM，Keil MDK V5 C99

AT32F435 · 差分 OTA 固件升级系统（改进版）

面向 AT32F435（1024 KB Flash / 128 KB SRAM）的安全差分 OTA 升级系统， 三重保障：BSDIFF 差分极小化补丁体积 + LZMA 压缩 + AES-128-CTR 加密。 双分区架构配合 CRC32 校验和自动回滚，确保升级零砖。

  • BSDIFF 二进制差分算法，补丁体积极小化
  • LZMA 流式高效压缩，进一步降低传输开销
  • AES-128-CTR 对称加密，固件防篡改
  • CRC32 完整性全程校验
  • 双分区（App1 / App2）+ Bootloader 三区架构
  • 升级失败自动回滚，零砖机风险
  • W25Q64 外部 Flash 存储差分包 + AT24C02 参数记录
