project overview

AT32F415 无刷直流电机电子调速器

基于雅特力 AT32F415CBT7（Cortex-M4，144 MHz）的双模式 BLDC 电调系统。默认以 AS5600 磁编码器实现有感 FOC 矢量控制，可通过编译宏一键切换至 BEMF 过零检测无感六步换相驱动。电流环设计参考 VESC 开源电调的 PI 抗饱和策略（电压包络约束），支持转矩、速度、位置、功率、制动、回馈制动六种控制模式。

条件编译方案

在 src/main.c 第 15 行通过注释控制模式选择，无需修改任何其他文件：

/* Uncomment to select six-step BEMF mode instead of FOC */
/* #define USE_BEMF_SIXSTEP */

#ifdef USE_BEMF_SIXSTEP
#include "sixstep_mode.h"
#else
#include "foc_mode.h"
#endif

该宏同时影响 vofa_debug.c 中的遥测通道定义——FOC 模式输出 12 个浮点通道（三相电流 + dq + αβ + 速度 + 电角度等），六步模式输出 5 个通道（RPM、步序、占空比、编码器角度、编码器速度）。BSP 驱动层在两种模式下均编译，按需调用。

切换模式后只需 重新编译，无需修改任何硬件配置或 BSP 文件。

功率级拓扑

三相全桥拓扑，每相由一个高侧 N-MOSFET 和一个低侧 N-MOSFET 构成半桥臂（两个 WSD3072DN33 封装各集成两个半桥臂，共六个 MOSFET）。FD6288Q 内部集成 3 路自举二极管，外置 100 nF 自举电容维持高侧栅极驱动电压；高/低侧栅极各串联 22 Ω 限流电阻抑制振荡与 EMI。

死区时间 Td = DTG × Tdts = 100 × (1 / 144,000,000) ≈ 694 ns
PWM 中心对齐频率 f = Fclk / (2 × ARR) = 144MHz / (2 × 3600) = 20 kHz
最大 D 轴参考电压 ULIMIT = Udc / √3 = 12.6 / 1.732 ≈ 7.27 V

电流采样链路

采用三相低侧串联采样拓扑：在每相下桥臂与 GND 之间串联 5 mΩ / 3 W 采样电阻（R128/R129，第三相由 Ia+Ib 计算），经 INA240A1 差分放大 20 倍后送入 MCU ADC。

Vshunt = Iphase × Rshunt = I × 0.005 V/A
Vout_INA240 = 1.65 + Vshunt × Gain = 1.65 + I × 0.1 V
ADC_code = Vout × 4096 / 3.3 → I(A) = (ADC_code − offset) × 0.008057

输出端串联 100 Ω 限流电阻与 22 nF 滤波电容（截止频率 ≈ 72 kHz），滤除 PWM 开关噪声后接入 PA2/PA3/PA6 三路 ADC。零偏在上电时对 64 次采样取均值完成校准，存储于 CurrentSense_t.offset_Ia/Ib/Ic。

FOC 矢量控制理论基础

三相 BLDC 电机定子产生的合成磁场方向由三相电流向量决定。传统六步换相方式下，磁场每步跳变 60° 电角度，导致转矩脉动。FOC 的核心思想是通过坐标变换，将三相交流量投影到与转子同步旋转的 dq 坐标系——d 轴分量控制磁通（保持为 0 可最大化转矩/安培比），q 轴分量直接等比于输出转矩。控制器在 dq 坐标系中处理的是直流量，可直接使用 PI 控制器实现无静差跟踪。

电机电压方程（dq 坐标系）：
Vd = Rs·Id + Ld·(dId/dt) − ωe·Lq·Iq
Vq = Rs·Iq + Lq·(dIq/dt) + ωe·Ld·Id + ωe·Ψm

输出转矩：Te = (3/2) × Pp × (Ψm·Iq + (Ld−Lq)·Id·Iq)
当 Id=0 时（表面贴装磁钢，Ld≈Lq）：Te ≈ (3/2) × Pp × Ψm × Iq

其中 Rs 为定子电阻，Ld/Lq 为 d/q 轴电感，ωe 为电角速度，Ψm 为永磁体磁链，Pp 为极对数。本项目 Pp=7，Id 目标设为 0，转矩控制实质上等价于对 Iq 的精确控制。

坐标变换

Clarke 变换（三相 → 静止 αβ）

三相平衡约束 Ic = −(Ia + Ib)，将三相变量投影到正交静止坐标系：

Iα = Ia
Iβ = (Ia + 2·Ib) / √3 = (1/√3)·Ia + (2/√3)·Ib

代码实现（foc_lib/foc_math.c）：

void foc_clarke(float Ia, float Ib, float *Ialpha, float *Ibeta)
{
    *Ialpha = Ia;
    *Ibeta  = (Ia + 2.0f * Ib) * FOC_1_SQRT3;  /* FOC_1_SQRT3 = 1/√3 */
}

Park 变换（静止 αβ → 旋转 dq）

以当前电角度 θ 为旋转参考，将静止坐标系投影到与转子磁场同步旋转的坐标系：

Id = Iα·cos(θ) + Iβ·sin(θ)
Iq = −Iα·sin(θ) + Iβ·cos(θ) 
void foc_park(float Ialpha, float Ibeta, float cos_t, float sin_t,
              float *Id, float *Iq)
{
    *Id =  Ialpha * cos_t + Ibeta * sin_t;
    *Iq = -Ialpha * sin_t + Ibeta * cos_t;
}

逆 Park 变换（dq 电压 → αβ）

Uα = Ud·cos(θ) − Uq·sin(θ)
Uβ = Ud·sin(θ) + Uq·cos(θ) 
void foc_inv_park(float Ud, float Uq, float cos_t, float sin_t,
                  float *Ua, float *Ub)
{
    *Ua = Ud * cos_t - Uq * sin_t;
    *Ub = Ud * sin_t + Uq * cos_t;
}

电角度 θ = (shaft_angle mod 2π) × POLE_PAIRS，由 AS5600 累计角度乘极对数计算。

空间矢量脉宽调制（SVPWM）

SVPWM 将 αβ 平面的参考电压矢量分解到相邻两个有效基本矢量（V1~V6）与零矢量（V0/V7）的作用时间，然后对称分配到每个 PWM 周期内（中心对齐）。相比正弦调制，SVPWM 的直流利用率更高（提升约 15%）。

6 个扇区判断参考量：
ref1 = Uβ
ref2 = (−Uβ + √3·Uα) / 2
ref3 = (−Uβ − √3·Uα) / 2

以扇区 1（ref1≥0, ref2≥0, ref3<0）为例：
t1 = Uα/Udc − Uβ/(√3·Udc)，t2 = 2·Uβ/(√3·Udc)
t0 = (1 − t1 − t2) / 2（零矢量对称插入）
Da = t1+t2+t0，Db = t2+t0，Dc = t0

过调制时对 t1+t2 进行归一化（t1/= sum, t2/= sum）防止系数溢出。最终输出为 TMR1 三个通道的比较值（0~3600），配合硬件互补死区生成三相六路 PWM。

/* 扇区 1 示例（6 个扇区逻辑类似） */
t1 = ua - ub * FOC_1_SQRT3;
t2 = 2.0f * ub * FOC_1_SQRT3;
sum = t1 + t2;
if (sum > 1.0f) { t1 /= sum; t2 /= sum; }  /* 过调制归一化 */
t0 = (1.0f - t1 - t2) * 0.5f;
Da = t1 + t2 + t0;  Db = t2 + t0;  Dc = t0;
*ta = (uint32_t)(Da * PWM_PERIOD);  /* PWM_PERIOD = 3600 */

电流环设计（VESC 参考）

RL 电机模型为一阶系统，不需要 D 分量，仅使用 PI 控制器。设计参考 VESC 的电压包络抗饱和策略：先约束 Ud 不超过总电压限幅，再用剩余电压空间约束 Uq，同时将积分器钳位至可实现范围内，从根本上防止积分饱和。

Ud_raw = Kp_d·(Id_sp − Id_m) + Ki_d·∫(Id_sp − Id_m)dt
Ud = clamp(Ud_raw, −ULIMIT, +ULIMIT)

max_Uq = √(ULIMIT² − Ud²) ← 电压圆约束
Uq_raw = Kp_q·(Iq_sp − Iq_m) + Ki_q·∫(Iq_sp − Iq_m)dt
Uq = clamp(Uq_raw, −max_Uq, +max_Uq)
积分器钳位：Ki_q.integral = clamp(Ki_q.integral, −max_Uq, +max_Uq)

当前参数（src/foc_mode.c）：

参数d 轴q 轴说明
Kp3.03.0比例增益，与电机电感正相关
Ki800.0800.0积分增益，与电机电阻正相关
limit7.27 V动态（max_Uq）输出电压限幅
/* VESC 抗饱和实现（src/foc_mode.c foc_current_loop()）*/
Ud = clampf(pid_update(&pid_Id, Id_sp - Id_m, now_us), -ULIMIT, ULIMIT);
max_vq = sqrtf(ULIMIT * ULIMIT - Ud * Ud);
Uq = clampf(pid_update(&pid_Iq, Iq_sp - Iq_m, now_us), -max_vq, max_vq);
/* 积分器钳位 */
if (pid_Iq.integral >  max_vq) pid_Iq.integral =  max_vq;
if (pid_Iq.integral < -max_vq) pid_Iq.integral = -max_vq;

Id 目标常量为 0（表面贴装磁钢，无需弱磁控制）。Iq 目标由外层速度环或直接命令提供。

速度环与位置环

速度环（PI）

error_ω = direction × target_ω − ω_measured
Iq_sp = Kp_vel·error_ω + Ki_vel·∫error_ω·dt
Iq_sp = clamp(Iq_sp, −CURRENT_LIMIT, +CURRENT_LIMIT)

参数：Kp=0.5，Ki=5.0，output_ramp=20 A/s（防止电流急变），limit=5 A。

位置环（级联 P + 速度环）

error_θ = target_θ − shaft_angle
ω_sp = Kp_pos·error_θ
Iq_sp = 速度环(ω_sp − ω_measured)

参数：Kp_pos=10.0，limit=60 rad/s（速度饱和防止超调）。

功率控制模式

ω_eff = clamp(|ω|, POWER_MIN_OMEGA=5, VELOCITY_LIMIT=60)
Iq_sp = direction × target_P / (Kt × ω_eff)
其中 Kt = TORQUE_CONST = 0.060 N·m/A

低速时 ω_eff 下限 5 rad/s 防止除零，同时避免低速大电流过热。

回馈制动模式

iq_pwr = regen_power_limit / (Kt × ω_eff)
Iq_sp = −direction × min(brake_current, iq_pwr)

通过功率限制防止回馈能量过大损坏电源；低速段线性衰减防止锁死。

FOC 启动流程详解

1
ALIGN（500ms）：施加 Ud=1.5V 至电角度 0° 方向（d 轴对准 A 相），通过逆 Park + SVPWM 产生定向磁场，将转子锁定到已知位置。零状态 500ms 后记录此时的 AS5600 角度作为电角度偏置 elec_angle_offset。
2
OPENLOOP（开环加速，10→50 rad/s）：以 300 rad/s² 加速度线性递增开环电角度 ol_angle，施加固定 Uq=1.2V 驱动转子跟随旋转磁场。速度超过 HANDOFF_SPEED=50 rad/s 后切换至 FOC 闭环。
3
FOC（编码器闭环）：切换至 AS5600 实时电角度反馈，电流闭环接管。速度环从 pid_vel 积分器清零开始平滑过渡，防止突变。

收到反向命令 → 置 reverse_pending=1，控制模式不切换
2
compute_iq_target() 检测到 pending → 施加 REV_BRAKE_I=1.8A 反向制动电流（方向由当前速度符号决定，不依赖旧的方向标志）
3
速度降至 ±SPEED_EPS=1 rad/s → 更新 run_direction，清除 pending，重置速度 PI 积分器，无需重新 ALIGN 直接在 FOC 状态内换向
整个换向过程不离开 FOC 状态，无需重新对齐，实现平滑无冲击反转。

六步换相原理

六步换相（梯形波驱动）在每个电气周期（360°）内将三相绕组的通电状态分为六个 60° 区间，每个区间仅两相导通，第三相浮空（高阻态）。通过悬浮相的 BEMF 过零点判断转子位置，在正确时刻触发下一步换相，从而在无编码器情况下实现自同步运行。

步序相 A相 B相 C悬浮相BEMF 过零方向
0+PWM−GNDFloatC上升（C BEMF ↑）
1+PWMFloat−GNDB下降（B BEMF ↓）
2Float+PWM−GNDA上升（A BEMF ↑）
3−GND+PWMFloatC下降（C BEMF ↓）
4−GNDFloat+PWMB上升（B BEMF ↑）
5Float−GND+PWMA下降（A BEMF ↓）

逆时针（CCW）换相序只需将步序反向（5→4→3→2→1→0→5...），由 motor_ctrl.c 的 direction 字段控制查表方向。

BEMF 过零检测实现

硬件路径

BEMF 反馈通过分压网络（10kΩ + 1kΩ，比例约 0.909，100nF 低通滤波）将相电压衰减至 MCU ADC 允许范围，同时接入 MCU 内置比较器 CMP1。虚拟中性点（各相分压电阻的公共点 CC_1）固定接 CMP1 同相输入（PA1）。每一步换相后，根据悬浮相（A/B/C）切换 CMP1 的反相输入引脚（PA0/PA4/PA5）。

过零判断逻辑（偶数步序：BEMF 上升）：ZC = (CMP_output → 0)
过零判断逻辑（奇数步序：BEMF 下降）：ZC = (CMP_output → 1)

滤波与消隐

  • 消隐时间（Blanking）：换相后 350 µs 内屏蔽所有过零检测，防止 MOSFET 切换瞬态（振铃、续流二极管恢复）触发误检。
  • 多重确认滤波：需连续 5 次 CMP 输出一致才判定为有效过零，屏蔽单次噪声干扰。
  • 检测窗口：过零有效窗口设为上一换相周期的 50%~140%，超出下限（太早）忽略，超时（太晚，>140%）强制换相（stall 计数 +1）。
/* bsp_bemf.c - 根据步序切换比较器反相输入 */
static const uint8_t cmp_phase[] = {
    CMP_INV_PA5,  /* step 0: C float */
    CMP_INV_PA4,  /* step 1: B float */
    CMP_INV_PA0,  /* step 2: A float */
    CMP_INV_PA5,  /* step 3: C float */
    CMP_INV_PA4,  /* step 4: B float */
    CMP_INV_PA0,  /* step 5: A float */
};

六步换相状态机详解

1
IDLE：所有 PWM 输出禁止，FD6288 使能引脚拉低。等待 motor_ctrl_start() 调用。
2
ALIGN（500ms）：施加低占空比（duty=1600/3600≈44%）固定在步序 0（A+ B−），强制转子对齐到第 0 步对应的磁场方向，建立已知初始位置。同时完成高侧自举电容预充电（pwm6s_bootstrap_charge()）。
3
RAMP（强制换相加速）：以初始 20ms 换相周期强制递推步序，每步后按一定步长缩短换相间隔，直至周期降至 1.5ms（约 333Hz 换相频率，对应 4762 RPM/极对数 ERPM）。期间一旦检测到第一个有效过零即切换至 RUN 状态。
4
RUN（BEMF 闭环）：以 BEMF 过零为换相触发，PI 速度环根据 target_rpm 和实测 RPM（由换相周期估算）调节 duty。RPM 估算公式：RPM = 60,000,000 / (comm_period_us × POLE_PAIRS)。
5
BRAKE：全部低侧 MOSFET 导通（pwm6s_brake_low_side()），三相电机绕组短接产生制动转矩。持续时间由 brake_duration_us 控制；设为 0 则持续制动直至 motor_ctrl_release_brake()。
6
FAULT（堵转保护）：RUN 状态下连续 STALL_FORCE_MAX=30 次强制换相（等效 45ms@1.5ms 最小周期）无有效过零检测 → 进入 FAULT，禁止所有输出，需手动调用 motor_ctrl_stop() 清除。

方向切换

运行中调用 motor_ctrl_set_direction() 时，若当前方向与目标不同，状态机自动：

  1. 进入 BRAKE（制动 200ms）
  2. 设置 restart_pending=1，记录目标方向
  3. 制动结束后以新方向重新进入 ALIGN → RAMP 流程

六步换相时序分析

换相频率：f_comm = RPM × Pp / 60
换相周期：T_comm = 60 / (RPM × Pp)

在 RPM=1000，Pp=7 时：T_comm = 60/(1000×7) ≈ 8.57ms
消隐时间（固定）：350µs = 350/8570 ≈ 4.1% 换相周期
过零理论位置：T_comm/2（步序中点，30° 电角度内）

RAMP 最小周期：1500µs → 最高无感同步速度约 RPM = 60M/(1500×7) ≈ 5714 RPM

AS5600 磁编码器驱动

DMA 自动刷新架构

初始化后，as5600_start_dma_read() 发起第一次 I2C+DMA 传输（写入寄存器地址 0x0E，然后读取 2 字节角度数据）。DMA 接收完成中断触发 as5600_dma_complete_handler()，解析角度后立即重新发起下一次传输，形成无限自循环，无需主循环介入。

1
DMA1_CH1 发送：I2C START + 设备地址(0x6C) + 寄存器地址(0x0E)
2
I2C 自动生成重复起始条件 Repeated Start
3
DMA1_CH2 接收：读回 2 字节原始角度（高字节 [11:8] + 低字节 [7:0]）
4
DMA RX 完成中断：raw = (buf[0]<<8 | buf[1]) & 0x0FFF → 更新 g_as5600_raw → 重新发起传输

刷新频率约 2kHz（400kHz I2C，每次 2 字节传输消耗约 500µs）。主循环调用 as5600_update_m0(&enc, now_us) 读取最新原始值并计算累计角度与速度，无阻塞。

shaft_angle += delta （cumulative，跨圈处理）
delta = angle_now − angle_prev，若 |delta| > π 则跨圈补偿
velocity = delta / Ts [rad/s]
el_angle = norm( shaft_angle × POLE_PAIRS + offset ) mod 2π

INA240 电流传感器驱动

ADC1 工作于 APB2_CLK/6=12 MHz（满足 AT32F415 最大 ADC 频率 28MHz），右对齐 12-bit 模式，软件触发单通道顺序采样三相。上电时调用 current_sense_calibrate() 对 64 次样本取均值作为零偏基准。

Iphase = (ADC_raw − offset) × Vref / (MaxADC × Gain × Rshunt)
= (ADC_raw − offset) × 3.3 / (4096 × 20 × 0.005)
= (ADC_raw − offset) × 0.008057 A/count

FOC 模式每控制周期（~1ms）采样一次 Ia、Ib，Ic 通过 Ic=−(Ia+Ib) 计算（三相平衡约束）。六步模式当前仅用于遥测与潜在的过流检测，不参与换相逻辑。

VOFA+ 实时调试

通过 USART3（PB10，115200bps，8N1）以 JustFloat 协议持续输出遥测帧。上位机 VOFA+ 配置为 JustFloat 帧类型、COM 口 115200bps 即可实时显示波形。

帧格式

/* JustFloat 帧结构（每帧 N 个 float + 4 字节尾标） */
[float0 4B][float1 4B]...[floatN-1 4B][0x00][0x00][0x80][0x7F]
 ch0         ch1                        └────── IEEE 754 NaN ────┘

/* 发帧速率：1kHz（每 1ms 一帧）via VOFA_WAVE_INTERVAL_US = 1000 */

VOFA+ 中 NaN 尾标（0x00 0x00 0x80 0x7F）是 JustFloat 协议的帧同步标志，必须位于每帧末尾。

PID 调参指南

电流环调参（foc_mode.c pid_Iq / pid_Id）

以 VOFA+ 观察 ch6(Iq) 跟踪 ch11(Iq_target) 的响应：

  1. 将 Kp 从小增大，直到 Iq 响应快速但无明显超调（阶跃响应上升沿约 2~5ms）
  2. 增大 Ki 消除稳态误差，直到低频稳定性下降为止
  3. 若 Iq/Id 出现高频振荡，检查 LPF 时间常数是否过长（增大 lpf_Iq.Tf 滤除噪声）

速度环调参（foc_mode.c pid_vel）

以 VOFA+ 观察 ch9(velocity) 跟踪速度设定值的响应：

  1. 先仅启用 Kp，调至速度动态响应满意（通常 0.1~1.0）
  2. 加入 Ki 消除稳态误差（通常 1~10），注意 output_ramp 控制 Iq 斜率防止突变
  3. 若出现转速低频抖动，增大 lpf_vel.Tf（速度滤波时间常数，当前 5ms）

六步速度 PI（motor_ctrl 的 speed_kp/speed_ki）

  1. 先设 Ki=0，调 Kp 直到 RPM 响应无明显超调
  2. 加 Ki 消除稳差，注意 Ki 过大会导致 RUN 状态 duty 振荡，触发 BEMF 误检
调参时建议使用转矩控制模式（foc_cmd_set_torque()）固定 Iq，直接验证电流环；再切换到速度模式验证速度环，避免两层 PID 同时引入干扰变量。
