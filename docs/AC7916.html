Project Overview

AC7916AB 蓝牙声控设备

基于杰理 AC79NN 芯片的多功能蓝牙音频解决方案，支持蓝牙双模（发射/接收）切换、 四声道 DAC 环绕声输出、USB 大容量存储、SD 卡播放、多模式按摩控制等功能。 项目集成完整的软硬件一体化设计方案，适用于智能音频外设开发。

AC79NN 双核处理器 LLVM 编译 蓝牙 5.0 + EDR 四声道 DAC USB Mass Storage SD 卡 FATFS 发射/接收双模 SPP 数传 4 种按摩模式
芯片: 杰理 AC7916AB (AC79NN)  ·  SDK: AC79NN_SDK_V1.2.0  ·  编译: LLVM  ·  Flash: 4 MB · SDRAM: 578 KB

系统架构

项目采用 5 层分层架构，覆盖蓝牙通信、音频处理、应用逻辑、存储管理和硬件驱动：

蓝牙通信层
A2DP 音乐 HFP 电话 SPP 数传 AVRCP 控制 发射/接收切换 bt_music.c bt_emitter.c
音频处理层
SBC 编解码 AAC 解码 mSBC 编解码 CVSD 编解码 MP3 解码 混音引擎 bt_decode.c
应用逻辑层
模式管理 按键处理 LED 指示 音量控制 App_mode.c mp3_play.c
存储管理层
SD 卡 FATFS USB MSD VM 配对存储 VFS 文件系统
硬件驱动层
GPIO PWM 气泵控制 DAC 四声道 ADC MIC Inf_key.c Inf_led.c Inf_extern.c

1

1

工作模式

系统支持 5 种工作状态，通过按键短按循环切换，长按开关机：

模式值LED 指示功能组合适用场景
MODE_SHUT_DOWN0全灭全部关闭待机状态
MODE_COMFORT1LED1气泵 + 缓慢充放气舒适护理
MODE_HOT2LED1-2气泵 + 加热温热按摩
MODE_VIBRATION3LED1-3气泵 + 振动 PWM强效刺激
MODE_PASSION4LED1-4气泵 + 加热 + 振动全功能组合

模式切换逻辑

// App_mode.c - App_switch_mode() 10ms 周期调用
长按 KEY (>2s):
├── 关机状态 → 开机 (MODE_COMFORT)
└── 开机状态 → 关机 (MODE_SHUT_DOWN)

短按 KEY:
├── 关机状态 → 无效
└── 开机状态 → 模式循环
    COMFORT → HOT → VIBRATION → PASSION → COMFORT

舒适模式气囊时序

气囊充放气循环周期 1.8 秒（180 × 10 ms），分为四个阶段：

1
缓慢放气（0–60 计数，0.6 秒） — 间歇放气，防止残留气体伤害
2
快速放气（60–90 计数，0.3 秒） — 持续放气，彻底清空气囊
3
快速充气（90–120 计数，0.3 秒） — 关闭放气阀，气囊快速膨胀
4
缓慢充气（120–180 计数，0.6 秒） — 周期性充气，微调压力，循环重置
